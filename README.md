## 🌐 Live Portfolio Website

This repository hosts my personal portfolio website built with **React**, **Styled-Components**, and custom visual themes.

- 🔗 **Live Demo**: [https://maulik22995.github.io](https://maulik22995.github.io)

### Local Development Setup

```bash
# Clone the repository
git clone https://github.com/maulik22995/maulik22995.github.io.git

# Navigate into project directory
cd maulik22995.github.io

# Install dependencies
npm install

# Start development server
npm start
```

### Production Build & Deploy

```bash
# Build optimized production bundle
npm run build

# Deploy to GitHub Pages
npm run deploy
```
